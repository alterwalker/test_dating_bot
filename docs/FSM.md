# FSM бота (Telegram)

Бот — тонкий клиент. Все данные через API. Состояния хранятся в памяти бота (или Redis позже); при рестарте — восстановление через `GET /profile`.

## Команды

| Команда | Действие |
|---------|----------|
| `/start` | регистрация, приветствие, переход к анкете или главному меню |
| `/profile` | просмотр / редактирование профиля |
| `/matches` | подбор пар (если профиль confirmed) |
| `/cancel` | сброс текущего шага FSM |

## Тексты сообщений (черновик)

### Welcome

```
Привет! Я помогу найти людей, с которыми вам правда интересно.

Ответьте на несколько вопросов — я разберу ваш профиль с помощью ИИ
и подберу совместимых людей.

[Создать профиль]  [У меня уже есть профиль]
```

### Промпты анкеты

**Идеальный вечер:**
```
Опишите идеальный вечер. Не одно слово — 2–4 предложения.
Например: пробежка, ужин дома, кино с друзьями...
```

**Ценности:**
```
Что для вас важно в отношениях?
Честность, юмор, общие планы, свобода, семья...
```

**Занятость:**
```
Чем вы занимаетесь и чем увлекаетесь?
Работа, хобби, спорт — всё, что считаете важным.
```

### Processing

```
⏳ Анализирую ваш профиль…
Обычно это занимает 10–20 секунд.
```

Polling: каждые 2 с, max 60 попыток → «Не удалось обработать, попробуйте позже».

### Confirm

```
Вот что я понял о вас:

📝 Кратко: {summary}

🏷 Интересы: {interests}
💎 Ценности: {values}
🎯 Цель: {relationship_intent}

[✅ Верно]  [✏️ Исправить текст]
```

### Main menu

```
Профиль готов!

[🔍 Найти пары]  [✏️ Изменить профиль]
```

### Matches

```
Нашёл {n} совместимых людей:

---
👤 {name}, {age}
⭐ Совместимость: {score}%

{explanation}

Общее: {shared_interests}
---
```

Пагинация: inline «Ещё» или top-5 за раз.

## Обработка ошибок

| Ситуация | Поведение бота |
|----------|----------------|
| API недоступен | «Сервис временно недоступен» |
| enrich failed | «Не получилось разобрать профиль. Попробуйте переформулировать ответы» + [Исправить] |
| matches без confirmed | «Сначала завершите профиль: /profile» |
| пустой список matches | «Пока мало людей в вашем городе. Загляните позже» |

## Inline-клавиатуры

**Gender:** `Мужской` | `Женский` | `Другое`

**Seeking:** toggle-кнопки `Мужчин` | `Женщин` | `Другое` + `[Готово]`

**Confirm:** `✅ Верно` | `✏️ Исправить`

**Main:** `🔍 Найти пары` | `✏️ Профиль`

---

## При рестарте бота

1. `POST /users` по `telegram_id`
2. `GET /profile`
3. если `confirmed` → MainMenu
4. если `ready` → Confirm
5. если `draft` + есть partial raw → продолжить с последнего незаполненного поля
6. иначе → Welcome
