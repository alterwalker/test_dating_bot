# Explainer — user message template

---

## Шаблон

```
Пользователь: {{.UserName}}, {{.UserAge}} лет, {{.UserCity}}

Его/её профиль:
- Интересы: {{.UserInterests}}
- Ценности: {{.UserValues}}
- Цель: {{.UserIntent}}
- Кратко: {{.UserSummary}}

---

Кандидат: {{.CandidateName}}, {{.CandidateAge}} лет

Профиль кандидата:
- Интересы: {{.CandidateInterests}}
- Ценности: {{.CandidateValues}}
- Цель: {{.CandidateIntent}}
- Кратко: {{.CandidateSummary}}

---

Совпадения (факты):
- Общие интересы: {{.SharedInterests}}
- Общие ценности: {{.SharedValues}}
- Совместимость intent: {{.IntentMatch}}
- Разница по оси «общительность»: {{.OutgoingDiff}}
- Разница по оси «семья»: {{.FamilyDiff}}

Объясни пользователю, почему этот человек может подойти.
```

## Пример

```
Пользователь: Анна, 28 лет, Москва

Её профиль:
- Интересы: бег, дизайн, собаки
- Ценности: честность, поддержка, общие планы
- Цель: serious
- Кратко: Product designer, бегает и живёт с собакой.

---

Кандидат: Кирилл, 29 лет

Профиль кандидата:
- Интересы: бег, путешествия, готовка
- Ценности: честность, юмор, верность
- Цель: serious
- Кратко: Инженер, бегает marathons, любит готовить.

---

Совпадения (факты):
- Общие интересы: бег
- Общие ценности: честность
- Совместимость intent: да
- Разница по оси «общительность»: 0.15
- Разница по оси «семья»: 0.10

Объясни пользователю, почему этот человек может подойти.
```

## Пример ответа LLM

```
Вам обоим близки бег и честность в отношениях, а вы оба ищете серьёзные отношения.
Кирилл по темпу жизни похож на вас — не экстраверт и не домосед в крайности.
Разные хобби (у него готовка и путешествия) могут как раз добавить разнообразия.
```
